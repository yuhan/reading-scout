# Maintaining Reading Scout

Users install from the `yuhan/reading-scout` repo marketplace by following the README.

`plugin.json` defines the plugin, and `.agents/plugins/marketplace.json` lists it in the repo marketplace. The skill is in `skills/reading-scout/`, and the listing icon is `assets/icon.svg`.

Before release, test a fresh installation and setup with the chosen X and queue connections.

For updates, bump the version in `plugin.json` and push the changes to `main`.
